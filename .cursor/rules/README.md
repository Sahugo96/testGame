# cursor_rules — необязательные Cursor-правила

Только для работы в Cursor. В базу знаний Claude Project эти файлы **не загружать**.

1. Положите файлы `*.mdc` в `.cursor/rules/` репозитория.
2. Положите набор документов (`00_INDEX.md`, `AI_INSTRUCTIONS.md`, `01`–`06`) в папку `docs/` репозитория.
3. Файлы в этой папке производные: источник правды — документы набора (`01_DEV_PLAN.md` §6 и §6.1, `02_OVERLAY_UI.md` 7.13). При расхождении прав документ; при изменении правил сначала правится документ, затем эти файлы.

Не включены: `ecs-code-standards.mdc` (противоречит стеку, устаревший API), `transcript-analysis.mdc` и `SKILL.md` (инструменты разбора видеокурса, не относятся к самой игре). Если вы продолжаете разбирать видеокурс в Cursor, оставьте их у себя отдельно и добавьте в `core-always.mdc` строку про `transcript-analysis`.
