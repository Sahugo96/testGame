> Версия набора документов: 14 (записаны решения разработчика по части открытых вопросов; ранее: исправление неточностей плана, интеграция Cursor-правил, решение по ECS, добавлен AI_INSTRUCTIONS.md, PROJECT_STATE v9 разделён на файлы по направлениям).
> Проект: многопользовательская RPG в духе Royal Quest на Unity. Правила работы ИИ — в `AI_INSTRUCTIONS.md`, описание проекта и план — в `01_DEV_PLAN.md`.

## Как пользоваться (Claude Project)

1. Загрузите все файлы набора в базу знаний проекта. Старый `PROJECT_STATE.md` удалите, чтобы не было двух версий одной информации.
2. Начиная новый чат, называйте нужные файлы. Всегда нужны `AI_INSTRUCTIONS.md`, `00_INDEX.md` и `01_DEV_PLAN.md`, остальные берутся по теме задачи. Пример первого сообщения: «Прочитай AI_INSTRUCTIONS.md, 00_INDEX.md, 01_DEV_PLAN.md и 03_CLASSES_COMBAT.md. Задача: модуль 5».
3. Одна тема — один файл. Информация не дублируется между файлами; если нужно сослаться, указывается номер раздела.
4. Номера разделов (7.1 ... 7.14.3), номера модулей и номера открытых вопросов сквозные и не меняются при переносе между файлами.
5. В репозитории набор лежит в `docs/`; точка входа для Claude Code — `CLAUDE.md` в корне, навигация по разделам — `docs/MAP.md`.

## Глоссарий

- **Боевая мана / резервная мана** — два пула маны, стартовый максимум каждого — 100; сначала тратится боевая (восстанавливается в бою), затем резервная (7.1).
- **Вариант навыка** — обычный, усиленный (Shift), ослабленный (Ctrl) (7.2).
- **Оверлей** — слой интерфейса поверх мира; **окно** — отдельная механика, открываемая кнопкой меню, клавишей или NPC (7.13).
- **Реестр окон** — данные, из которых строится меню и окна (7.13).
- **Комплект экипировки (loadout)** — сохранённая раскладка для быстрой смены (7.7); не путать с бонусными наборами (отложено).
- **ДЕФОЛТ** — временное решение, меняется по слову разработчика; перечислено в «Открытых вопросах» каждого файла.
- **Модуль** — этап разработки из плана (раздел 8 в `01_DEV_PLAN.md`).

## Как обновлять

После каждого модуля:
0. Процедура подробно описана в `AI_INSTRUCTIONS.md`, раздел 4.
1. В `01_DEV_PLAN.md` обновить статус в таблице раздела 8, реестр модулей (9), проблемы (10), журнал решений (11).
2. Обновить только те тематические файлы, которых коснулись изменения; поднять «Версию файла».
3. Добавить строку в журнал изменений ниже.
4. Выдавать полные обновлённые версии изменённых файлов, остальные не трогать.
