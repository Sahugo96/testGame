# Как сыграть вдвоём с другом — пошагово

> Короткая инструкция. Подробности и решения проблем — `docs/HOW_TO_RUN.md`, раздел 9.
> Версия файла: 2 (сборка с протоколом версии 14, модули 20 и 17).

Игра — один файл `MyGame.exe`: он и клиент, и сервер. **Ты** создаёшь сервер на своём компьютере и играешь на нём сам, **друг** подключается к тебе. Персонажи и всё имущество (рюкзак, золото, лавки, почта) хранятся у тебя.

---

## Шаг 1. Ты: обнови код и собери игру

Это нужно делать **каждый раз после обновления кода**: старая сборка друга к новому серверу не подключится («версия игры не совпадает»).

1. Закрой Unity.
2. В папке репозитория (`D:\UnityGameDev\testGame`) открой терминал и забери свежий код:
   ```bash
   git pull origin claude/vertical-slice
   ```
3. Открой проект в Unity Hub (`My project`, версия **6000.3.19f1**), дождись окончания импорта.
4. Открой *Window → General → Console*: красных ошибок быть не должно. Если они есть — пришли мне первую целиком и дальше не иди.
5. Меню сверху: **Game → Build Windows (client + server)**. Подожди несколько минут.
6. Откроется папка `My project\Builds\Windows`: `MyGame.exe`, папка `MyGame_Data` и `.bat`-файлы.

Если Unity пишет, что сборка под Windows не установлена: Unity Hub → *Installs* → шестерёнка у 6000.3.19f1 → *Add modules* → **Windows Build Support (Mono)**.

## Шаг 2. Ты: отправь игру другу

1. Правый клик по папке `Windows` → *Сжать в ZIP-файл*.
2. Отправь архив другу (облако, мессенджер).
3. Друг **распаковывает** архив целиком в любую папку. Из самого архива игра не запустится, а один `MyGame.exe` без `MyGame_Data` не работает.

## Шаг 3. Вы оба: сделайте общую сеть

Проще всего — **Radmin VPN** (бесплатно, работает через интернет, порты на роутере настраивать не нужно):

1. Оба скачиваете и ставите Radmin VPN (radmin-vpn.com).
2. Ты: *Сеть → Создать сеть* — придумай имя и пароль, скажи их другу.
3. Друг: *Сеть → Присоединиться к существующей сети* — вводит имя и пароль.
4. В окне Radmin у тебя отображается твой адрес вида **`26.x.x.x`** — он понадобится другу.

Если вы в одной домашней сети (один роутер), Radmin не нужен: адрес — твой локальный, вида `192.168.x.x`.

## Шаг 4. Ты: запусти сервер

1. Запусти `MyGame.exe` (или `StartHost.bat` — он сразу создаёт сервер).
2. В меню впиши имя персонажа, выбери класс → **«Создать сервер (хост)»**.
3. Windows спросит про брандмауэр — нажми **«Разрешить доступ»** (отметь и частные, и общественные сети).
4. Внизу слева появится строка «Сервер запущен, порт 7777. Адреса этого компьютера: …». Продиктуй другу адрес, начинающийся с `26.` (для Radmin) или с `192.168.` (одна сеть).

## Шаг 5. Друг: подключись

1. Запусти `MyGame.exe` из распакованной папки.
2. В меню:
   - **Имя** персонажа (уникальное на сервере) и **класс**;
   - **Адрес сервера** — тот, что ты продиктовал; **порт** — 7777;
   - **Логин и пароль** — любые новые (первый вход регистрирует аккаунт на твоём сервере; потом входить тем же логином и паролем).
3. **«Подключиться»**. Вы увидите друг друга, над персонажами — имена.

## Шаг 6. Что попробовать вместе

| Что | Как |
|---|---|
| Чат | `Enter` → текст → `Enter`; кнопка слева от поля — канал: «Рядом», «Мир», «Группа», «Шёпот». Вкладки «Общий» и «Личное» над чатом |
| Друзья | `F` → имя персонажа друга → «Отправить заявку» → друг жмёт «Принять» |
| Группа | кликни по другу → «В группу» → друг жмёт «Принять»; окно группы — `P` |
| Обмен | встаньте рядом, кликни по другу → «Обмен»; **не двигайтесь**, пока меняетесь — любой шаг отменяет обмен |
| Дуэль | кликни по другу → «Дуэль» |
| Лавка | светлый диск «Место для лавки» (впереди справа) → название, уровень → «Открыть лавку»; кликни по своему торговцу и выставь вещи |
| Рынок | золотистый куб впереди слева → поиск по всем лавкам → «Купить» |
| Почта | синий куб рядом с рынком → «Новое письмо» с вещами и золотом; друг забирает у своего ящика |
| Заказ улучшения | точильный камень → «Заказы»: ты отдаёшь предмет и оплату серверу, друг улучшает его своими осколками и получает оплату |
| Настройки | `O`: графика (на этом компьютере), клавиши, камера и интерфейс (в аккаунте — у друга свои) → «Применить» |
| Разделить стопку | рюкзак `I` → перетащи стопку в пустую ячейку с `Shift` (половина) или `Ctrl` (одна штука) |

## Шаг 7. Выйти и вернуться

- Выйти: `O` → «Выйти в главное меню». Прогресс сохраняется при выходе, раз в минуту и при закрытии игры.
- Сохранения лежат **у тебя**: `%USERPROFILE%\AppData\LocalLow\DefaultCompany\My project\Saves`. Пока твоя игра-сервер закрыта, друг зайти не сможет. Сроки лавок и писем идут по реальному времени и тогда: если срок лавки вышел, пока сервер был выключен, она закроется при следующем запуске, а нераспроданное придёт владельцу на почту.
- В следующий раз: ты снова «Создать сервер», друг — «Подключиться» с **тем же логином и паролем**.

## Если что-то не так

| Сообщение | Что делать |
|---|---|
| «Не удалось подключиться: No answer from …» | проверь адрес; ты нажал «Создать сервер»; оба в одной сети Radmin (зелёный значок у друга в списке); брандмауэр разрешён для `MyGame` |
| «версия игры не совпадает…» | у вас разные сборки: собери заново (шаг 1) и отправь свежий архив (шаг 2) |
| «сервер не знает выбранный класс» | то же: разные данные игры |
| неверный пароль | друг входит другим паролем, чем в первый раз; или пусть возьмёт новый логин |

Если не помогло, пришли мне: текст сообщения, способ соединения (Radmin / одна сеть) и у себя файл `%USERPROFILE%\AppData\LocalLow\DefaultCompany\My project\Player.log`.

**Безопасность:** пароль передаётся без шифрования — используйте отдельный пароль только для этой игры.
