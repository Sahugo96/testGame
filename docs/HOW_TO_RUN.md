# HOW_TO_RUN.md — как установить, открыть и запустить проект

> Для: Windows 10/11, Unity 6.3 LTS (**6000.3.19f1**), Unity Hub 3.x. Код игры — в ветке `claude/vertical-slice` репозитория `https://github.com/Sahugo96/testGame`.
> Ничего настраивать в сцене не нужно: игра собирается сама, когда запускается сцена `SampleScene`.
> Начинаешь с нуля — иди по разделам 0 → 1 → 2 → 3 → 4, затем по разделу 10 (проверка по шагам).

## 0. Установка с нуля (один раз)

**0.1. Git.** Скачай с `https://git-scm.com/download/win` и установи с настройками по умолчанию. Проверка — в терминале (Пуск → «Терминал» или «Git Bash»):
```bash
git --version
```
Должна напечататься версия. Вместо командной строки можно пользоваться **GitHub Desktop** — шаги для него ниже, в разделе 1.

**0.2. Доступ к репозиторию.** Нужен аккаунт GitHub с доступом к `Sahugo96/testGame`. Если репозиторий закрытый, при первом `git clone` откроется окно входа в GitHub в браузере — войди тем аккаунтом, у которого есть доступ.

**0.3. Unity Hub и лицензия.**
1. Скачай Unity Hub с `https://unity.com/download` и установи.
2. Открой Hub и войди (Unity ID; если его нет — *Create account*).
3. Hub попросит лицензию: *Manage licenses* (или *Preferences → Licenses*) → *Add* → **Get a free personal license**.

**0.4. Редактор 6000.3.19f1 — именно эта версия.** Проще всего поставить его на шаге 2.2: Hub сам увидит, что проекту нужна 6000.3.19f1, и предложит *Install Version 6000.3.19f1*. Если хочешь заранее: Hub → *Installs* → *Install Editor* → вкладка *Archive* (или страница `https://unity.com/releases/editor/archive` → найди 6000.3.19f1 → *Install*).
- Модули при установке: **дополнительно ничего не нужно** — сборка под Windows (Mono) входит в редактор для Windows. По желанию — *Microsoft Visual Studio Community* (удобно читать и править код). *Windows Build Support (IL2CPP)*, Android, WebGL — не нужны.
- Другую версию (даже 6000.3.x с другим последним номером) не ставь: Unity предложит «обновить» проект и поменяет его файлы. Если 6000.3.19f1 недоступна — напиши мне, какие 6000.3.x есть в списке.
- Место на диске: редактор ~10 ГБ, проект после первого открытия ~3 ГБ (папка `Library`, в git не попадает).

**0.5. .NET 8 SDK — по желанию.** Нужен только для тестов и нагрузочного теста без Unity (разделы 6 и 9.6а): `https://dotnet.microsoft.com/download/dotnet/8.0` → *SDK*.

## 1. Получить код

### 1.1. Первый раз: склонировать

1. Выбери папку **без русских букв в пути** (например `D:\UnityGameDev`) и открой в ней терминал (в проводнике: правый клик по папке → «Открыть в терминале» или *Git Bash Here*).
2. Склонируй сразу нужную ветку (основная ветка `main` старая — без `-b` получишь не тот код):
   ```bash
   git clone -b claude/vertical-slice https://github.com/Sahugo96/testGame.git
   ```
3. Появится папка `D:\UnityGameDev\testGame`, в ней — папка Unity-проекта `My project`. Проверка:
   ```bash
   cd testGame
   ```
   ```bash
   git branch
   ```
   Должно быть `* claude/vertical-slice`.

Через GitHub Desktop: *File → Clone repository → URL* → `https://github.com/Sahugo96/testGame` → *Local path* `D:\UnityGameDev\testGame` → *Clone*; затем вверху *Current branch* → `claude/vertical-slice` (на вкладке *Remote*, если её нет среди локальных).

### 1.2. Если репозиторий у тебя уже есть (на другой ветке)

1. **Закрой Unity** (иначе при переключении ветки редактор начнёт импортировать файлы посреди операции).
2. В папке репозитория:
   ```bash
   git status
   ```
   Если что-то изменено (Unity часто сама меняет файлы в `My project/ProjectSettings` и `My project/UserSettings`), отложи изменения:
   ```bash
   git stash -u
   ```
3. Забери ветку и переключись на неё:
   ```bash
   git fetch origin
   ```
   ```bash
   git checkout claude/vertical-slice
   ```

Если Git не даёт переключиться из-за файлов `My project/Temp/...` (`UnityLockfile`, `FSTimeGet-...`) или `My project/UserSettings/Layouts/default-6000.dwlt`: закрой Unity полностью, выполни `git restore "My project/UserSettings/Layouts/default-6000.dwlt"`, удали папку `My project\Temp` и снова `git checkout claude/vertical-slice`.

### 1.3. Обновлять потом (когда появятся новые коммиты)

Закрой Unity, затем:
```bash
git pull origin claude/vertical-slice
```
Если `pull` отказывается из-за файлов, которые поменяла Unity, в `My project/Packages` или `My project/ProjectSettings`, — верни их и повтори `pull`:
```bash
git checkout -- "My project/Packages" "My project/ProjectSettings"
```

## 2. Открыть проект

1. Unity Hub → *Projects* → *Add* (или *Open*) → *Add project from disk* → выбери папку `D:\UnityGameDev\testGame\My project` (именно её — где лежат `Assets`, `Packages`, `ProjectSettings`).
2. Если редактора 6000.3.19f1 ещё нет, Hub покажет предупреждение у проекта — нажми *Install Version 6000.3.19f1* (модули — как в 0.4) и дождись установки.
3. Открой проект. **Первое открытие идёт долго (5–15 минут)**: Unity скачивает пакеты (Localization, Addressables, Input System, URP), импортирует скрипты и данные, строит папку `Library`. Нужен интернет. Не трогай редактор, пока внизу справа крутится индикатор.
4. Окна, которые могут появиться:
   - **«Enter Safe Mode?»** — нажми *Enter Safe Mode* (это безопасно), открой *Window → General → Console* и пришли мне **первые 3–5 красных строк целиком** (подробнее — 10.3);
   - **предложение обновить проект на другую версию Unity** — откажись (*Cancel* / *Quit*) и выбери 6000.3.19f1 в колонке *Editor Version* у проекта в Hub;
   - **предложение обновить пакеты** — откажись.

## 3. Проверить, что всё скомпилировалось

1. Открой окно **Console**: *Window → General → Console* (или `Ctrl+Shift+C`).
2. Красных ошибок быть не должно. Жёлтые предупреждения можно игнорировать.
3. Если есть красные ошибки — **пришли первую из них целиком** (текст, файл и номер строки, например `Assets/_Project/Scripts/Client/UI/HudRoot.cs(42,13): error CS...`). Пока ошибки есть, кнопка Play не запустит игру.

## 4. Запустить игру

1. В окне *Project* открой `Assets/Scenes/SampleScene` (двойной клик). Обычно она уже открыта.
2. Нажми **Play** (треугольник вверху по центру).
3. Появится **стартовое меню**: введи имя, выбери класс и нажми **«Одиночная игра»** (игра с другом — раздел 9).
4. **Кликни мышью внутри окна Game** — иначе клавиатура уходит в редактор, а не в игру.
5. Удобно развернуть окно игры: в окне *Game* включи *Maximize On Play* (или нажми `Shift+Space`, наведя мышь на окно Game).
6. Если интерфейс выглядит слишком мелким/крупным — в окне *Game* выбери разрешение **Full HD (1920×1080)** в выпадающем списке вверху (по умолчанию *Free Aspect*). Интерфейс масштабируется сам.

Если игра не появилась (серый экран без интерфейса):
- проверь Console — при ошибке в данных там будет `[Content] ...` с описанием проблемы;
- убедись, что запущена именно сцена с именем `SampleScene` (игра стартует только в ней — так задано в `Assets/_Project/Resources/Content/base/config.json`, поле `BootstrapScene`).

|---|---|
| Движение | `W A S D` или стрелки (относительно камеры) |
| Поворот камеры | зажать **правую** кнопку мыши и вести |
| Приблизить / отдалить | колесо мыши |
| Выбрать цель | **левый клик** по манекену или `Tab` (ближайшая цель) |
| Сбросить цель / закрыть окно | `Esc` |
| Навыки | `1` … `0`, `-`, `=` (первый ряд панели) или клик по ячейке |
| Усиленный вариант навыка | держать `Shift` + клавиша навыка |
| Ослабленный вариант | держать `Ctrl` + клавиша навыка (в редакторе Unity `Ctrl+цифра` может открыть окно редактора — тогда кликай по ячейке с зажатым `Ctrl` или проверяй в билде) |
| Персонаж | `C` или кнопка «Перс.» слева от панели навыков |
| Рюкзак | `I` или кнопка «Рюкз.» |
| Таланты | `N` или кнопка «Тал.» (пока заглушка) |
| Карта | `M` или кнопка «Карта» |
| Умения (мастерство) | `K` |
| Боевой лог | `L` |
| Настройки | `O`: вкладки «Графика» (качество, разрешение, режим окна, VSync, ограничение кадров, счётчик FPS), «Управление» (переназначение клавиш, камера), «Интерфейс» (масштаб, прозрачность, числа урона, имена), «Игровые» (автоподбор, вкладки чата, смена класса Маг/Воин, «Выйти в главное меню»). Изменения — кнопкой «Применить» |
| Точильный камень (улучшение предметов) | **левый клик по светло-серому колесу** слева позади точки появления, стоя рядом |
| Наковальня (создание предметов) | **левый клик по тёмной наковальне** справа позади точки появления, стоя рядом |
| Дуэль | выбрать другого игрока (клик) → кнопка **«Дуэль»** справа от рамки цели; у соперника появится панель «Принять / Отклонить» |
| Группа | выбрать другого игрока → **«В группу»** слева от рамки цели; окно группы — `P` (состав, лидер, исключить, покинуть, режим лута и голосование, журнал лута) |

| Друзья | `F` или кнопка «Друзья» внизу справа: имя персонажа → «Отправить заявку»; у второго — «Принять / Отклонить»; у друзей — «Шёпот», «Удалить» |

| Рынок, лавка, почта | **левый клик** стоя рядом: по золотистому кубу «Главный управляющий рынком» (рынок), по синему кубу (почта), по светлому диску «Место для лавки» (открыть свою лавку), по торговцу над диском (купить или управлять своей лавкой). Рынок и почта — впереди слева от точки появления, места для лавок — впереди справа |

| Панель навыков | перетащи навык из книги умений (`K`) на любую из 3×12 ячеек; ячейку на ячейку — поменять местами; ячейку за пределы панели — убрать. Раскладка хранится на сервере у персонажа |
| Панель расходников | перетащи зелье из рюкзака (`I`) на ячейку над панелью навыков; клик — выпить (берётся любая стопка этого вида) |
| Комплекты экипировки | окно «Персонаж» (`C`) → вкладка «Дополнительно» → «Сохранить» запоминает надетое, «Надеть» — надевает; в бою меняется только оружие |

Что попробовать:
- Маг: выбери манекен (`Tab`), нажми `1` («Огненный шар», каст 1,5 с; если двигаться — каст прервётся), `Shift+1` — усиленный, `3` — «Вспышка резерва» (тратит и основную, и резервную ману).
- Потрать основную ману до нуля — статус «Основная мана заблокирована»: пока резерв не полон, основная пассивно не растёт; зелье (кнопки над панелью навыков) её восстанавливает.
- Рюкзак: клик по предмету — надеть/использовать; «Железный шлем» Маг надеть не может (латы).
- Персонаж: клик по надетому предмету — снять; справа вкладки «Основные» и «Дополнительно».
- Кубы (жёлтые, впереди слева от точки появления): 1 HP, 10 опыта, возрождаются через 5 с; иногда роняют осколок философского камня (отсек «Ресурсы»). Полоса опыта — внизу справа; на новом уровне в окне персонажа появятся кнопки «+».
- Рюкзак (`I`): вкладки «Экипировка», «Расходники», «Лут», «Ресурсы», «Квестовые»; у Воина в «Экипировке» — комплект мечника, надень его по клику.
- Точильный камень (светло-серое колесо слева позади точки появления): подойди, кликни, выбери предмет и нажми «Улучшить» — тратится 1 осколок, шанс 100%, 95%, 90%… до +10. При неудаче уровень снижается на 1. Если отойти или вступить в бой, окно закроется.
- Наковальня (тёмный блок справа позади точки появления): выбери рецепт (железный шлем, железный меч, шлем мечника), посмотри материалы и шанс, нажми «Создать». Создание идёт несколько секунд; если отойти или вступить в бой — прервётся без потерь. При неудаче материалы теряются.
- **Опасные мобы:** справа впереди от точки появления — стая из трёх **волков**: подойдёшь ближе 8 м — нападут, кусают, гонятся; если убежать далеко, вернутся на место и вылечатся. Слева далеко — **каменный голем**: сам не нападает, но если ударить, бьёт сильно и оглушает. С волков и голема падают железная руда (для наковальни) и осколки. Кого атакует моб, видно под рамкой цели («→ имя»). Умер — возрождение через 5 с у точки появления.
- Статусы: `Shift+1` у мага («Огненный шар» усиленный) поджигает цель — под рамкой цели появится красная плашка «Горение» с таймером, урон идёт каждую секунду (складывается до 3 раз). У Воина `Shift`+«Мощный удар» оглушает, «Кровавый удар» снижает оборону. Эликсиры «Железная кожа» и «Ярость» (рюкзак → «Расходники») дают зелёную плашку у твоей рамки; второй эликсир заменяет первый. Наведи на плашку — подсказка. Всё видно в боевом логе (`L`).
- Настройки (`O`) → «Игровые» → «Воин» (смена класса): другие навыки («Кровавый удар» платит здоровьем и может убить), щит и меч; «Большой топор» — двуручный.

## 9. Игра по сети с другом

Короткая пошаговая версия этого раздела — `docs/PLAY_WITH_FRIEND.md`.

Игра — один файл `MyGame.exe`: он умеет быть и клиентом, и сервером. Один из вас **создаёт сервер (хост)** и играет на нём сам, второй **подключается**. Собрать `.exe` можно только в твоём Unity (облако, где я работаю, Unity не запускает).

### 9.1. Собрать игру (один раз после каждого обновления кода)

1. Отдельный модуль не нужен: сборка под Windows (Mono) входит в редактор для Windows. Если Unity всё же скажет, что платформа не установлена, — Hub → *Installs* → шестерёнка у **6000.3.19f1** → *Add modules*, и пришли мне, что там предлагается.
2. В Unity сверху меню **Game → Build Windows (client + server)**. Сборка займёт несколько минут.
3. Когда закончится, откроется папка `D:\UnityGameDev\testGame\My project\Builds\Windows`. В ней `MyGame.exe`, папка `MyGame_Data` и файлы `StartHost.bat`, `StartServer.bat`, `StopServer.bat`, `StartBots.bat`. В git эта папка не попадает.
4. Чтобы отправить другу: правый клик по папке `Windows` → *Сжать в ZIP* (или *Отправить → Сжатая ZIP-папка*). Отправь архив целиком; другу его нужно **распаковать** (из архива игра не запустится). Отдельно один `.exe` без `MyGame_Data` не работает.

**Важно:** у тебя и у друга должна быть одна и та же сборка. Если версии разные, сервер откажет: «версия игры не совпадает с версией сервера».

### 9.2. Как соединиться: выбери один вариант

Сервер слушает **TCP-порт 7777** (меняется в `Assets/_Project/Resources/Content/base/config.json` — поле `DefaultPort` — или параметром `-port`).

| Вариант | Когда | Что сделать |
|---|---|---|
| **А. Одна сеть (Wi-Fi/роутер)** | вы рядом | ничего; адрес — локальный IP хоста (вида `192.168.x.x`) |
| **Б. VPN-«локалка» (проще всего через интернет)** | вы в разных местах | оба ставите **Radmin VPN** (или ZeroTier), один создаёт сеть, второй входит в неё. Адрес — IP хоста в Radmin VPN (вида `26.x.x.x`) |
| **В. Проброс порта** | у хоста «белый» IP | в настройках роутера пробросить TCP 7777 на компьютер хоста; адрес — внешний IP хоста (2ip.ru). У многих провайдеров это не работает (общий IP) — тогда вариант Б |

При первом запуске сервера Windows спросит про **брандмауэр** — нажми **«Разрешить доступ»** (поставь галочки и для частных, и для общественных сетей). Если окно не появилось, а друг не может подключиться: *Панель управления → Брандмауэр Защитника Windows → Разрешить взаимодействие с приложением* → найти `MyGame` и поставить обе галочки.

### 9.3. Играть

**Хост (ты):**
1. Запусти `MyGame.exe` (или `StartHost.bat` — он сразу создаёт сервер).
2. В меню: имя, класс → **«Создать сервер (хост)»**.
3. Внизу слева появится строка «Сервер запущен, порт 7777. Адреса этого компьютера: …» — продиктуй другу нужный адрес (для Radmin — тот, что начинается с `26.`; его же видно в окне Radmin VPN).

**Друг:**
1. Распаковать архив, запустить `MyGame.exe`.
2. В меню: имя, класс, в поле «Адрес сервера» — адрес хоста, порт 7777, **логин и пароль** (первый вход с новым логином — регистрация на сервере хоста) → **«Подключиться»**.
3. Вы увидите друг друга (над персонажем — имя), можно вместе бить кубы и манекены.

**Добыча:** в настройках (`O`) — кнопка «Автоподбор добычи». Включён (по умолчанию) — добыча сразу в рюкзаке. Выключен — падает на землю цветным шариком (цвет — редкость, над ним название): кликни по нему, стоя рядом. В группе с режимом «Поднявшему» и ручным подбором поднимает тот, кто успел первым. Если отсек полон — предмет тоже остаётся на земле. Лежит 5 минут.

**Группа:** кликни по другу → «В группу» слева от рамки цели → друг жмёт «Принять». Рамка друга появится под твоей (клик по ней — выбрать его целью, например для лечения). В окне `P` можно предложить режим лута «Лидеру» или «По очереди» — у второго появится панель «За / Против»; меняется только при согласии всех. Лут получает тот, кто участвовал в бою (бил моба или лечил бьющего) и стоит не дальше 50 м.

**Дуэль:** кликни по другу → «Дуэль» справа от рамки цели → друг жмёт «Принять». После отсчёта 3 с появится красный круг: выйдешь за него — поражение. Дуэль не до смерти: последний удар оставляет 1 HP. «Сдаться» — на панели дуэли, через 3 минуты — ничья. Вызвать нельзя в бою и дальше 10 м.

**Настройки (`O`):** что поменял — действует после «Применить»; «Отмена» — вернуть как было, «По умолчанию» — для открытой вкладки.
- *Графика* хранится на твоём компьютере. Новое разрешение или режим окна нужно подтвердить кнопкой «Оставить» за 15 секунд — иначе вернётся прежнее (на случай, если экран погас). В редакторе Unity разрешение не меняется — проверяй в собранной игре.
- *Управление*: нажми на клавишу действия → «Нажмите клавишу…» → нажми новую (`Esc` — отмена). Если клавиша уже занята, внизу появится «Заменить» (у другого действия клавиша снимется), «Поменять» (обменяться клавишами) или «Отмена». Новые клавиши сразу видны на панели навыков и кнопках меню.
- *Управление*, *Интерфейс* и клавиши хранятся **в аккаунте на сервере**: друг, войдя со своим логином на другом компьютере, получит свои настройки.

**Вкладки чата:** «Общий» показывает всё, «Личное» — только шёпот. Кнопка «Вкладки» над чатом (или `O` → «Вкладки чата»): выбери вкладку, впиши название, отметь, что показывать (`[x]` — показывается), «Новая вкладка» / «Удалить вкладку» / «По умолчанию», затем «Сохранить». Вкладки хранятся в аккаунте. Вкладка с новыми сообщениями подсвечивается оранжевым.

**Чат:** `Enter`, пиши, `Enter`. «Рядом» слышат те, кого ты видишь; «Мир» — все на сервере; «Группа» — твоя группа или рейд (сюда же приходят строки «[Система]» о голосованиях и составе); «Шёпот» — один персонаж по имени (регистр не важен). Не чаще двух сообщений в секунду, до 200 символов.

**Друзья:** `F` → впиши имя персонажа друга → «Отправить заявку». У друга в окне `F` появится «хочет дружить» с кнопками «Принять / Отклонить» (и строка в чате), даже если он сейчас не в игре — увидит при входе. После согласия вы есть друг у друга в списке: «в сети / не в сети», «Шёпот», «Удалить» (удаляет у обоих). Свою заявку можно «Отозвать».

**Обмен:** стойте рядом (не дальше 10 м, не в бою) и **не двигайтесь** — любой шаг любого из вас сразу отменяет обмен (тот, кто предложил, должен стоять уже пока ждёт ответа). Кликни по другу → «Обмен» → друг жмёт «Принять». Откроется окно: внизу твоя сумка — клик по предмету кладёт его в обмен, клик по предмету в левой колонке убирает; золото — впиши число → «Указать золото». Справа — что отдаёт друг. Когда оба нажмут «Подтвердить», вещи и золото поменяются местами; любое изменение снимает подтверждения. Закрыть окно = отменить обмен. Привязанные и божественные предметы передать нельзя.

**Рейд:** лидер группы в окне `P` жмёт «Сделать рейдом» — можно до 50 человек, отряды по 5 (номер отряда — в квадратных скобках у имени). Лидер назначает «Помощника» — помощники тоже приглашают и двигают людей кнопками «Отряд −» / «Отряд +». Рамки слева сверху показывают только твой отряд. За режим лута в рейде голосуют лидер и первые участники каждого отряда.

**Лавка (своя торговля):** подойди к светлому диску «Место для лавки» (их 4 в ряд впереди справа от точки появления), кликни → впиши название, выбери уровень лавки (комиссия, сколько лотов, сколько часов, аренда) → «Открыть лавку». Над диском встанет твой торговец с названием. Кликни по нему: внизу — твоя сумка; впиши «Цена за шт.» и кликни по предмету — стопка выставлена целиком (чтобы продать часть, сначала раздели стопку в рюкзаке перетаскиванием). У лотов: «Цена» — поменять цену, «Снять» — вернуть в сумку. Лавка работает, даже когда ты не в игре; когда время выйдет (или «Закрыть лавку»), нераспроданное придёт на почту.

**Рынок:** у золотистого куба «Главный управляющий рынком» — поиск по всем лавкам: название, категория, класс, уровень, слоты, улучшение, редкость, цена, сортировка. Впиши количество → «Купить». Покупка сразу в сумку (если места нет — на почту). Деньги продавцу приходят письмом за вычетом комиссии лавки.

**Почта:** синий куб «Почтовый ящик». Слева письма (● — непрочитанное), справа выбранное: «Забрать всё» (вещи и золото сразу; нужно место в сумке), «Удалить» (когда письмо пустое). «Новое письмо»: кому (имя персонажа, можно не в сети), тема, текст, вложения (клик по предметам сумки) и золото; сбор — 5 золота за каждое вложение. Не забранное письмо через 30 дней вернётся отправителю. Новые письма видно строкой «Новых писем: N» под мини-картой.

**Заказ улучшения:** точильный камень → «Заказы». Внизу выбери предмет, впиши оплату и (по желанию) имя кузнеца → «Создать заказ»: предмет и оплата уходят на хранение серверу. Друг у того же камня видит заказ → «Выполнить»: он тратит свои осколки и золото шага, получает оплату, а улучшенный (или неудачно улучшенный) предмет приходит тебе письмом. Свой открытый заказ можно «Отменить».

Выйти — `O` → «Выйти в главное меню». Если хост закрыл игру, у друга появится «Соединение с сервером потеряно». Персонаж сохраняется на сервере хоста (см. 9.3а).

### 9.3а. Сохранения

- Прогресс сохраняется: при выходе, раз в минуту и при закрытии игры. Обмен между игроками, покупки, почта, лавки и заказы записываются **сразу и целиком** (оба участника и рынок одной записью через файл-журнал `commit.json`): после сбоя предмет не пропадёт и не удвоится. Следующий вход тем же логином (у друга) или той же игрой (у тебя) вернёт уровень, предметы, место и статусы.
- У каждого аккаунта по персонажу на класс: выбрал в меню другой класс — это другой персонаж того же аккаунта. Имя персонажа уникально на сервере.
- Где лежат: `%USERPROFILE%\AppData\LocalLow\DefaultCompany\My project\Saves` (у хоста — все аккаунты его сервера; рядом `backups` — копии на момент каждого запуска, хранятся 5 последних, и `audit` — журнал операций с предметами). Начать заново — удалить папку `Saves` при закрытой игре.
- Пароль по сети не шифруется — используйте отдельный пароль, только для этой игры.

### 9.4. Отдельный сервер без графики (по желанию)

Если хочется, чтобы сервер работал отдельно от игры (например, на третьем компьютере):
- `StartServer.bat` — запускает сервер без окна и показывает его лог (`server.log`): адреса, «Players online: N».
- `StopServer.bat` — останавливает его **с сохранением**: создаёт файл `server.stop`, сервер сохраняет всех и выходит; если за 30 с не вышел — закрывается силой (тогда теряется прогресс с последнего автосохранения).
- Потом все, включая тебя, подключаются через «Подключиться» (на том же компьютере адрес `127.0.0.1`).

Параметры командной строки `MyGame.exe`: `-server` (сервер без графики), `-host`, `-connect <адрес>`, `-port <число>`, `-name <имя>`, `-class <mage|warrior>`.

### 9.5. Проверить сеть на одном компьютере

Запусти `MyGame.exe` дважды: в первом окне «Создать сервер», во втором — «Подключиться» с адресом `127.0.0.1`. Окна работают одновременно (игра не засыпает в фоне).

### 9.6а. Боты и нагрузка (по желанию)

- `StartBots.bat` рядом с `MyGame.exe` спросит адрес сервера и число ботов и запустит их без окна (лог — `bots.log`). Боты ходят, выбирают цели и применяют навыки, как игроки.
- Выделенный сервер (`StartServer.bat`) каждые 10 с пишет в `server.log` строку `Metrics:` — время тика, число игроков и сущностей, трафик на игрока.
- Без игры (нужен .NET 8): `cd tools/LoadTest` и `dotnet run -c Release -- local 50 60` — сервер и 50 ботов в одном процессе; подробности — `tools/LoadTest/README.md`.

### 9.6. Если не подключается

- «Не удалось подключиться: No answer from …» — неверный адрес, сервер не запущен, брандмауэр или (вариант В) порт не проброшен. Проверь, что хост нажал «Создать сервер» и видит строку с адресами.
- «версия игры не совпадает…» — у вас разные сборки: собери заново и отправь другу свежий архив.
- «сервер не знает выбранный класс» — у вас разные данные игры, то же решение.
- «данные игры отличаются от данных сервера» — сборки собраны из разного контента (карточек, JSON): собери заново и отправь другу.
- Пришли мне: текст ошибки из меню, какой вариант соединения, и у хоста — файл `server.log` (отдельный сервер) или `%USERPROFILE%\AppData\LocalLow\DefaultCompany\My project\Player.log` (обычный запуск).

### 10.11. Сборка и игра по сети

1. **Game → Build Windows (client + server)** (раздел 9.1). В Console — `[Build] Done`. Перед сборкой редактор сам сверит карточки и JSON и соберёт таблицы текстов (Addressables); при ошибках контента сборка остановится и покажет их.

## 11. Контент и тексты в Unity (модуль 4)

### 11.1. Первое открытие

Разделы 2 и 10.4–10.9: пакеты, карточки, Localization, проверка, коммит.

### 11.2. Как править контент

- **Карточки:** выдели карточку в `Assets/_Project/Content/<пакет>/<тип>/` (например `base/mobs/wolf`) — в инспекторе поле *Data* со всеми параметрами. Меняй; через ~1,5 с редактор сам запишет JSON (`Resources/Content/<пакет>/…json`) и проверит контент. Ошибки — красными строками `[Content]` в Console.
- **Перед Play и перед сборкой** синхронизация и проверка выполняются сами; со сломанным контентом сборка остановится и покажет ошибки.
- **Я правлю JSON в облаке** — после `git pull` редактор сам перенесёт мои изменения в карточки. Если ты и я поменяли одно и то же одновременно, побеждает JSON, а твоя версия сохранится в `My project/Library/ContentConflicts` (в Console будет предупреждение с путём).
- **Новая запись:** **Game → Content → New item… / New mob… / New skill… / New class…** — выбери пакет, «копию чего» сделать, новый Id (латиница, цифры, `_`), название и описание по-русски → *Create*. Карточка откроется в инспекторе, тексты попадут в `ru.json` и таблицу.
- **Удалять выпущенные записи нельзя** (их могут хранить сохранения): поставь у предмета, моба или рецепта галочку *Deprecated* — он перестанет выпадать, создаваться и появляться, но у кого он есть — останется. Список выпущенных Id — `Resources/Content/content_ids.json` (новые Id добавляются сами).
- **Новый пакет** (например событие): **Game → Content → New pack…** → Id → *Create*; затем мастерами создавай записи, выбирая этот пакет. Пакет только добавляет новое; менять записи `base` из пакета нельзя.
- **Лимиты баланса** (защита от опечаток): карточка `Content/base/balance_limits` — потолки характеристик предмета по редкости и статусов. Сильный предмет не проходит — подними потолок там.

### 11.3. Баланс в Excel / Google Таблицах

**Game → Content → Balance tables (CSV)…** → пакет и таблица (например `mobs`) → *Export to CSV…* → открой в Excel (разделитель `;`, дробные через запятую — под русский Excel). Меняй числа и тексты, сохрани как CSV → *Import from CSV…*. В таблице только простые поля и вложенные на один уровень; списки (компоненты, добыча, варианты навыков) — в карточке. Если в таблице ошибка (неизвестная колонка, текст вместо числа, несуществующий Id), не меняется ничего, а окно покажет, что исправить.

### 11.4. Тексты

- Все надписи — в таблице Unity Localization `Game` (*Window → Asset Management → Localization Tables*), источник для неё — `Resources/Localization/ru.json`. Правишь в таблице — редактор перенесёт в `ru.json`; я правлю `ru.json` — перенесётся в таблицу.
- Если Localization не настроена или таблица не загрузилась, игра берёт тексты из `ru.json` (в Console одно предупреждение).
- Язык выбирается в `O` → «Игровые» → «Язык» (кнопка появляется, когда языков больше одного). Новый язык добавляется в Unity: *Localization Tables* → *Locale Generator*, затем переводы в таблице `Game`.

### 11.5. Что прислать при ошибке

- Красные строки `[Content]` или `[Localization]` из Console целиком.
- Ошибки компиляции (особенно в `Editor/Content/*.cs`, `UnityLocalizationService.cs`) — первую целиком: эти части проверены только компилятором вне Unity.
- Если карточки не появились — есть ли папка `Assets/_Project/Content` и что в Console после *Game → Content → Sync cards and JSON*.
