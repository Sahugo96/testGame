# HOW_TO_RUN.md — как открыть и запустить проект

> Для: Unity 6.3 LTS (**6000.3.19f1**), Unity Hub любой версии 3.x. Код игры — в ветке `claude/vertical-slice`.
> Ничего настраивать в сцене не нужно: игра собирается сама, когда запускается сцена `SampleScene`.

## 1. Получить код (один раз)

Код лежит в ветке `claude/vertical-slice` на GitHub. Её нужно забрать в ту же папку, где у тебя уже лежит репозиторий (`D:\UnityGameDev\testGame`).

1. **Закрой Unity** (иначе при переключении ветки редактор начнёт импортировать файлы посреди операции).
2. Открой терминал в папке репозитория (в проводнике: правый клик по `D:\UnityGameDev\testGame` → «Открыть в терминале», или Git Bash).
3. Проверь, нет ли незакоммиченных изменений:
   ```bash
   git status
   ```
   Если что-то изменено (Unity часто сама меняет файлы в `My project/ProjectSettings` и `My project/UserSettings`), отложи изменения:
   ```bash
   git stash -u
   ```
4. Забери ветку и переключись на неё:
   ```bash
   git fetch origin
   ```
   ```bash
   git checkout claude/vertical-slice
   ```
   При переключении Git может удалить папку `My project/UserSettings` — это нормально: там только раскладка окон редактора, Unity создаст её заново.

Через GitHub Desktop: *Fetch origin* → в списке веток выбрать `claude/vertical-slice` → *Switch branch* (если спросит про изменения — выбрать *Leave my changes* / *Stash*).

Обновить ветку позже (когда появятся новые коммиты):
```bash
git pull origin claude/vertical-slice
```

## 2. Открыть проект

1. Запусти **Unity Hub**.
2. Если проект `My project` уже есть в списке *Projects* — просто открой его. Если нет: *Add* → *Add project from disk* → выбери папку `D:\UnityGameDev\testGame\My project` (именно её, где лежат `Assets`, `Packages`, `ProjectSettings`).
3. Убедись, что в колонке *Editor Version* стоит **6000.3.19f1**. Открой проект.
4. Первое открытие после переключения ветки займёт время: Unity импортирует новые скрипты и JSON-файлы и создаст для них `.meta`-файлы. Дождись, пока исчезнет полоса прогресса внизу справа.

## 3. Проверить, что всё скомпилировалось

1. Открой окно **Console**: *Window → General → Console* (или `Ctrl+Shift+C`).
2. Красных ошибок быть не должно. Жёлтые предупреждения можно игнорировать.
3. Если есть красные ошибки — **пришли первую из них целиком** (текст, файл и номер строки, например `Assets/_Project/Scripts/Client/UI/HudRoot.cs(42,13): error CS...`). Пока ошибки есть, кнопка Play не запустит игру.

## 4. Запустить игру

1. В окне *Project* открой `Assets/Scenes/SampleScene` (двойной клик). Обычно она уже открыта.
2. Нажми **Play** (треугольник вверху по центру).
3. **Кликни мышью внутри окна Game** — иначе клавиатура уходит в редактор, а не в игру.
4. Удобно развернуть окно игры: в окне *Game* включи *Maximize On Play* (или нажми `Shift+Space`, наведя мышь на окно Game).
5. Если интерфейс выглядит слишком мелким/крупным — в окне *Game* выбери разрешение **Full HD (1920×1080)** в выпадающем списке вверху (по умолчанию *Free Aspect*). Интерфейс масштабируется сам.

Если игра не появилась (серый экран без интерфейса):
- проверь Console — при ошибке в данных там будет `[Content] ...` с описанием проблемы;
- убедись, что запущена именно сцена с именем `SampleScene` (игра стартует только в ней — так задано в `Assets/_Project/Resources/Content/config.json`, поле `BootstrapScene`).

## 5. Управление

| Действие | Клавиша / мышь |
|---|---|
| Движение | `W A S D` или стрелки (относительно камеры) |
| Поворот камеры | зажать **правую** кнопку мыши и вести |
| Приблизить / отдалить | колесо мыши |
| Выбрать цель | **левый клик** по манекену или `Tab` (ближайшая цель) |
| Сбросить цель / закрыть окно | `Esc` |
| Навыки | `1` … `0`, `-`, `=` (первый ряд панели) или клик по ячейке |
| Усиленный вариант навыка | держать `Shift` + клавиша навыка |
| Ослабленный вариант | держать `Ctrl` + клавиша навыка (в редакторе Unity `Ctrl+цифра` может открыть окно редактора — тогда кликай по ячейке с зажатым `Ctrl` или проверяй в билде) |
| Персонаж | `C` или кнопка «Перс.» слева от панели навыков |
| Рюкзак | `I` или кнопка «Рюкз.» |
| Таланты | `N` или кнопка «Тал.» (пока заглушка) |
| Карта | `M` или кнопка «Карта» |
| Умения (мастерство) | `K` |
| Настройки (и смена класса Маг/Воин) | `O` |

Что попробовать:
- Маг: выбери манекен (`Tab`), нажми `1` («Огненный шар», каст 1,5 с; если двигаться — каст прервётся), `Shift+1` — усиленный, `3` — «Вспышка резерва» (тратит и основную, и резервную ману).
- Потрать основную ману до нуля — статус «Основная мана заблокирована»: пока резерв не полон, основная пассивно не растёт; зелье (кнопки над панелью навыков) её восстанавливает.
- Рюкзак: клик по предмету — надеть/использовать; «Железный шлем» Маг надеть не может (латы).
- Персонаж: клик по надетому предмету — снять; справа вкладки «Основные» и «Дополнительно».
- Настройки → «Воин»: другие навыки («Кровавый удар» платит здоровьем и может убить), щит и меч; «Большой топор» — двуручный.

## 6. Тесты (по желанию)

- В Unity: *Window → General → Test Runner* → вкладка **EditMode** → *Run All*. Все тесты должны быть зелёными.
- Без Unity (нужен .NET 8 SDK):
  ```bash
  cd sim-tests && dotnet test
  ```

## 7. Что прислать, если что-то не так

1. Первую красную ошибку из Console (текст целиком, файл, строка).
2. Что делал и что видно на экране (можно скриншот окна Game и Console).
3. Если игра запустилась, но поведение странное — какой класс, какая клавиша, что ожидал и что произошло.
