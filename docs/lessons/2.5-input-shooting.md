## Суть урока

Расширение pipeline ввода: **shoot action**, **OnScreenButton**, поле **`InputData.Shoot`**. Отдельная **`CharacterShootSystem`** с tag **`ShootData`**. Ссылки на **`IAbility`** (MonoBehaviour) нельзя положить в struct — hybrid MB **`UserInputData`** в query. **`ShootAbility.Execute()`** спавнит пулю; без проверки `shoot > 0` — вызов **каждый кадр** при hold. Фиксы: **one-shot callbacks** (`started`/`performed` vs `canceled→0`) и **rate limit** (`shootDelay` + `Time.time`). ДЗ: entity-пуля, dash, поворот к движению.

## CODE STANDARDS (VTT 2.5)

```csharp
public interface IAbility
{
    void Execute();
}
```

```csharp
public class UserInputData : MonoBehaviour, IConvertGameObjectToEntity
{
    public MonoBehaviour ShootAction; // authoring: ShootAbility

    public void Convert(Entity entity, EntityManager dstManager, GameObjectConversionSystem conversionSystem)
    {
        dstManager.AddComponentData(entity, new InputData());
        // MoveData — из 2.4
        if (ShootAction != null && ShootAction is IAbility)
            dstManager.AddComponentData(entity, new ShootData());
    }
}

public struct InputData : IComponentData
{
    public float2 Move;
    public float Shoot;
}

public struct ShootData : IComponentData { }
```

```csharp
// UserInputSystem — фрагмент shoot (аналог move)
private InputAction _shootAction;
private float _shootInput;

// OnStartRunning:
_shootAction = new InputAction("shoot");
_shootAction.AddBinding("<Keyboard>/space");
_shootAction.started += _ => _shootInput = 1f;
_shootAction.canceled += _ => _shootInput = 0f;
_shootAction.Enable();

// OnUpdate:
inputData.Shoot = _shootInput;
```

```csharp
public class CharacterShootSystem : ComponentSystemBase
{
    private EntityQuery _shootQuery;

    protected override void OnCreate()
    {
        _shootQuery = GetEntityQuery(
            ComponentType.ReadWrite<InputData>(),
            ComponentType.ReadOnly<ShootData>(),
            ComponentType.ReadOnly<UserInputData>());
    }

    protected override void OnUpdate()
    {
        Entities.With(_shootQuery).ForEach(
            (in InputData input, UserInputData userInput) =>
            {
                if (input.Shoot <= 0f) return;
                if (userInput.ShootAction is IAbility ability)
                    ability.Execute();
            }).Run();
    }
}
```

```csharp
public class ShootAbility : MonoBehaviour, IAbility
{
    public GameObject Bullet;
    public float ShootDelay = 2f;
    private float _shootTime;

    public void Execute()
    {
        if (Bullet == null) { Debug.LogError("No bullet prefab"); return; }
        if (Time.time < _shootTime + ShootDelay) return;
        _shootTime = Time.time;
        var t = transform;
        Instantiate(Bullet, t.position, t.rotation);
    }
}
```

## Не выносить в rules

- Конкретный UI-ассет «controls icons» / крестик кнопки.
- Домашнее задание (entity-пуля, dash, поворот) — scope DZ, не rule до реализации.
- «Двойная проверка is IAbility — привычка» — стиль автора, не архитектура.
- `Instantiate` без pool — demo; pool — позже.
- Автоконверт MB в ECS component «само» — наблюдение; явный `Convert` надёжнее.
