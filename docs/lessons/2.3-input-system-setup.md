## Суть урока

Установка пакета **Input System** через Package Manager, переключение backend (перезапуск редактора). Обзор **Input Settings Asset** (схемы ввода для разных устройств) и практического ядра — **Input Actions**: action maps → actions → bindings. Демонстрация **interactions** (Hold, Press, Slow Tap) и **processors** (нормализация значений). Кодовые биндинги и связка с персонажем — в 2.4–2.5.
