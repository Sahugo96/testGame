## Суть урока

Практика **Hybrid ECS + PhysX query**: `CapsuleCollider` → bake в `ActorColliderData` при `Convert` → `CollisionSystem` с `Overlap*NonAlloc` каждый кадр. Самоколлизия лечится `collider.enabled = false`. При hit — `CollisionAbility.Execute()`, не логика в системе.
