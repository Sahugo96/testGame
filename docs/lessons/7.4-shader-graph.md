## Суть урока

Практика **Standard (Built-in) Material**: PBR **Metallic/Smoothness**, режимы **Opaque / Cutout / Fade / Transparent**, maps, **Emission**, **GPU Instancing**. Кастомные эффекты — **Shader Graph** только с **URP/HDRP** (не Built-in): установка **Universal RP**, **Pipeline Asset**, upgrade materials, dissolve-demo (Noise + Time + Step + Alpha/Emission + **Property** `noiseScale`).
