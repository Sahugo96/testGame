## Суть урока

Монетизация требует **понимания игроков**. Базово — **store analytics** (загрузки, рейтинги, **crashes/ANR**, bad behavior → снижение органического трафика Google Play). Расширенно — **AppMetrica** (курс) / Firebase / Unity Analytics: **retention**, воронки. Обязанность dev: **debug symbols** для de-symbolicate crashes; **custom events** (`SendEvent`) — **technical funnel** (load level, config) и **user funnel** (tutorial steps, purchases). Отзывы 1★ — сигнал боли. Analytics — общая забота dev + product.
