## Суть урока

Обзор Unity VFX: **LineRenderer**, **Trail Renderer**, **Particle System** (+ Force Field). Particle System — **meta-комponent** с модулями (Emission, Shape, Color/Size over Lifetime, Collision, Triggers, Sub Emitters, Renderer Billboard/Mesh). Все модули доступны из **скриптов**. Perf: выключать неиспользуемые модули, **Culling Mode**, лимит **Max Particles**, осторожно с collision/shadows/light probes.
