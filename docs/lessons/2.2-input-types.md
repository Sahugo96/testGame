## Суть урока

Обзор типов ввода (клавиатура/мышь, touch, геймпад, VR) и мотивация перехода с **Legacy Input** на **New Input System**. Ключевая идея: физические устройства биндятся к **виртуальным действиям**; код не зависит от платформы. NIS задуман для ECS/DOTS. Практики в проект ещё не внедряются.
