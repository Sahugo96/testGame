## Суть урока

Установка/обновление **Unity Test Framework** (Package Manager). Окно **Test Runner**: **Edit Mode** vs **Play Mode** tests. Создать **Test Assembly** (`Tests` folder + `.asmdef` referencing `UnityEngine.TestRunner`, `NUnit`). **`[Test]`** (NUnit) vs **`[UnityTest]`** with `yield return null` для Play Mode. Подключить **asmdef references** к тестируемому коду (gameplay, Wwise, Photon, IAP — ожидать missing ref errors). Duplicate asmdef references ломают compile. Tests в **`Assets/_Project/Tests/`** или dedicated `Tests/` per architecture.
