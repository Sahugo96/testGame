## Суть урока

Ловушка (**активный объект**) наносит урон. **`TrapAbility : CollisionAbility`**. Проблема: `GetComponent<CollisionAbility>()` не находит наследника — **точное совпадение типа** в Hybrid/ECS. Решение: **`ICollisionAbility`**. Event-логика в **Ability**, не в idle System. `CharacterHealth` — demo-хранилище.

## CODE STANDARDS (VTT 3.4)

```csharp
public interface ICollisionAbility : IAbility
{
    IReadOnlyList<Collider> Collisions { get; }
}
```

```csharp
// CollisionSystem — НЕ GetComponent<CollisionAbility>()
var ability = gameObject.GetComponent<ICollisionAbility>();
if (ability != null) ability.Execute();
```

| ID | Стандарт |
|----|----------|
| CS-3.4-01 | `ICollisionAbility : IAbility` |
| CS-3.4-02 | System → `GetComponent<ICollisionAbility>()`, не concrete type |
| CS-3.4-03 | Контекст коллизий — property, заполняет system |
| CS-3.4-04 | `TrapAbility` override `Execute` (устарело в 3.5) |
