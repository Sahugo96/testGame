## Суть урока

Практика **Window → Rendering → Lighting**: **Lighting Settings Asset**, bake static objects + **Baked** directional, **Progressive CPU/GPU** (не Enlighten), **Shadowmask**, emissive bounce на пол. Dynamic character: **не дублировать** baked sun — **Mixed** light / **Point** fill; **Light Probe Group** + rebake. **Render Mode** Important/Not Important для лимита per-pixel lights. Realtime shadows дороги (soft хуже).
