## Суть урока

Теория игровой физики: дорогие вычисления → упрощённые **коллайдеры**; иерархия форм (сфера → капсула → бокс → mesh). Обзор движков Unity: **классический PhysX**, **Unity Physics** и **Havok** (DOTS). Плюсы DOTS-физики — детерминизм и состояние; для middle-курса выбран **классический Unity Physics**; DOTS-физика — в отдельном модуле.
