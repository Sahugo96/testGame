## Суть урока

Звук — атмосфера + обратная связь геймплея. **Music** (линейный саундтрек) vs **SFX** (позиционный, reverb zones, ambient). Встроенный Unity: **AudioListener** + **AudioSource** достаточно для prototype; production — **middleware** (**FMOD** free OSS-ish vs **Wwise** free tier + licensing). Эффекты: reverb volumes, 3D panning, voice limits. Тысячи одновременных `AudioClip.Play` — **perf + mud**. Production path курса → **Wwise** (16.3–16.4).
