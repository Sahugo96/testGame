## Суть урока

Теория **DOTS** (Entities, Jobs, Burst) и минусы стека (struct, blittable, preview, boilerplate). Критика **глубокого ООП** и **композиции без дисциплины** (GO + MonoBehaviour). Канон **ECS**: Entity = ID, Component = data, System = logic, **query** вместо ссылок.

**Слайды** добавляют **конкретные паттерны кода** курса: `*Data : IComponentData`, `GetEntityQuery` в `OnCreate`, `Entities.ForEach`, job с `[BurstCompile]`, и **осознанный hack** через reflection на `EntityManager` — «нельзя, но иногда приходится».
