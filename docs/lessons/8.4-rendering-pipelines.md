## Суть урока

**URP Asset** в Project Settings → Graphics: **shader stripping**, список renderer'ов, **Renderer Features** (SSAO, Render Objects experimental), **multiple renderers** по слоям. Секция Lighting: main/additional lights, **shadow cascades**, глобальный переключатель soft shadows, **Mixed lighting**, **SRP Batcher**, **Dynamic Batching**. **HDRP** — desktop/high-end, больше настроек, **Volumes** (post/sky/fog), procedural sky привязан к directional; нет отдельных URP-style renderer'ов. **Custom SRP** — C# class, тема для собеседования / углублённая тема.
