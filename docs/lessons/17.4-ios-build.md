## Суть урока

iOS: Unity **Build → Xcode project** (не IPA напрямую на Windows). Открыть в **Xcode**, настроить **Signing & Capabilities** (Team, provisioning profile, bundle id). **Apple Developer** account нужен для device test / store. IL2CPP, **Info.plist** permissions (camera, etc.) при добавлении SDKs. Archive → TestFlight / App Store Connect. Mac hardware required для финального pipeline.
