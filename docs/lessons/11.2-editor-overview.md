## Суть урока

Вводная о расширяемости редактора Unity: редактор построен на том же движке — API это обычные C#-скрипты и атрибуты. На примере `ScriptableObject` Settings показан `[CreateAssetMenu]` с явными `menuName` и `fileName`. Подчёркнуто, что весь Inspector — тоже скрипты с атрибутами; поведение «не как у наших MonoBehaviour» задаётся именно ими.
