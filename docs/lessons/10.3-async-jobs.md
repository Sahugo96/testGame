## Суть урока

Demo: блокирующий UI → исправление через **`async void` + `await Task.Delay`**. Параллельный CPU: **`Task.Run` + `Thread.Sleep`** в worker (не main thread). **Jobs**: struct `IJob`, **`NativeArray<float>` Allocator.TempJob**, присвоение в job field, **`Schedule().Complete()`**, **Dispose**. Не смешивать **`await Task.Delay`** с чтением job **`NativeArray`** после dispose (баг demo). **`IJobParallelFor`** с batch size; input+output **NativeArrays**. **`[BurstCompile]`** на hot jobs. **`IJobParallelForTransform`** для bulk transforms.
