## Суть урока

Обзор **отвязки данных от устройства**: профиль на сервере, live-настройки без нового билда, anti-cheat. Четыре опции (slide-01): **Google Sheets/Docs**, **собственный сервер** (DB + upload/download), **Photon** (облачные профили + multiplayer), **облака** (AWS, Azure). Компромиссы: бесплатный tier vs масштаб, DevOps-квалификация, стоимость при росте. Для обучения следующий урок — **Google Docs** в Unity.
