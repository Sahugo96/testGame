## Суть урока

Release build ≠ `Build` без подготовки. Обязательны **third-party SDK**: **Facebook SDK** (login/share/ads/analytics worldwide), **Yandex AppMetrica** (analytics RU + курс). Установка: download `.unitypackage` / importer, часто иерархия **`Plugins/`**. Качество SDK неоднородное — но отраслевой default. После import — resolve **Android/iOS manifest merges**, Gradle deps, define symbols. SDK до platform build (17.3–17.4).
