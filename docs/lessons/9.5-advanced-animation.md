## Суть урока

Обзор инструментов: **Timeline** (простой, для программистов чаще DOTween). **Final IK** ($) — inverse kinematics (feet, hands). **Spine** ($) — 2D skeletal. **Vertex Motion** ($) — GPU mesh deform, polish. **GPU Animation Baking** — bake skinning в shader для **crowds** (identical meshes/anims); perf ÷2 на каждый extra mesh variant. Third-party — по ADR, не default.
