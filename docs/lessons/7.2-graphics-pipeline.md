## Суть урока

Упрощённый **графический pipeline**: геометрия и текстуры в **видеопамяти** → **vertex/tessellation** → **rasterization** (рано, с **UV**) → **fragment** (normal map и т.д.) → **pixel** (отложенное освещение) → **framebuffer** → вывод с частотой монитора. DirectX/OpenGL/Metal/Vulkan на уровне Unity почти не различаются. Кастомизация pipeline — **Scriptable Render Pipeline** (отдельная deep-тема).
