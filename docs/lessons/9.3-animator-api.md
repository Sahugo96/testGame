## Суть урока

Hybrid: **`AnimData` : `IComponentData`** (hash names) + **`DogAnimSystem`** читает input, вызывает **`Animator.SetBool` / `SetFloat`**. Fix transitions: **Has Exit Time off** для responsive stop. Rotation — **`Quaternion.Lerp` * deltaTime**. Walk speed sync — float param **`WalkSpeed`**, связанный с multiplier **`AnimatorState.speed`** + tune input magnitude. Не смешивать Jobs/async с timing dispose **`NativeArray`** (fail демо).
