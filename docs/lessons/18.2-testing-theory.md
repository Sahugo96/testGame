## Суть урока

Партнёрство с QA: dev должны знать типы тестов и проектировать testability. **Functional** (соответствие design doc). **Combinatorial** (матрицы settings × progression). **Exploratory** (свежий взгляд). **Compatibility** (devices/OS/GPUs). **Performance/load**. **Playtesting** (особенно **network PvP/co-op**). **Regression** (live mobile SaaS — новая работа не ломает checklist 1.0). **Automated** tests дополняют manual; не заменяют exploratory для feel/net.
