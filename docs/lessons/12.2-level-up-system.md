## Суть урока

Практическая **система level-up** на компоненте `CharacterData`: score, порог `scoreToNextLevel`, метод `AddScore` вместо прямой записи в поля. Расширяемость через интерфейс **`ILevelUp`** и список **`LevelUpActions`** (MonoBehaviour на персонаже) — при level-up вызываются все реализации (пример: `LevelUpHealth`). Опционально **MinLevel** для апгрейдов с определённого уровня. Конфигурация — SO/JSON (модуль 4). Не singleton — уровень может быть у любой сущности.
