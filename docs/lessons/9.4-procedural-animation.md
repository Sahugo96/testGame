## Суть урока

Процедурная анимация — изменения **Transform** во времени; для non-skeletal / props. Пакет **DOTween** (free): `DOScale`, `DOMove`, **`OnComplete`**, **`Sequence`** (Append/Prepend). Trap demo: **`ShrinkAbility`** — guard flag, потому что **`Execute` каждый кадр** при collision. Альтернатива — one-shot collision. DOTween силён для **UI** tween.
