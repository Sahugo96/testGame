## Суть урока

Объём на экране — за счёт **освещения** (упрощённые модели вместо path tracing). Обзор **моделей освещения** (Blinn → Metal → Anisotropic → Strauss → Oren-Nayar-Blinn → Multi-Layer): **Blinn быстрее, физически богаче — медленнее**. **Direct vs deferred** — когда считаются источники. Карты: **Diffuse/Albedo**, **Specular**, **Displacement/Bump**, **AO**, **Normal** (RGB = сдвиг нормали во **fragment shader**).
