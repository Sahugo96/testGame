## Суть урока

Pickup через **Collision Ability** на ECS-сущности; для уничтожения — **`IConvertGameObjectToEntity`** + кеш **`Entity`/`EntityManager`**, destroy и GameObject, и entity. Инвентарь: **`IItem`** (`UiItem`, `UseItem(CharacterData)`), **`GiveItemPickupAbility`**, UI-префаб в **`CharacterData.InventoryRoot`**. Использование предмета — **`StarItemAbility`** (MonoBehaviour, не ECS). **`IAbilityTarget`** хранит владельцев; для простого кейса — один target. Клик по UI — `Button` → `Execute`. Демо: CharacterData **не хранит список** предметов — ownership на item side (loose coupling).
