## Суть урока

Gameplay **не держит ссылки на UI** — иначе «лапша связей». Паттерн **MVVM**: Model (CharacterHealth) ↔ **ViewModel** ↔ View (Text). Плагин **[UnityWeld](https://github.com/Real-Serious-Games/UnityWeld)** — `[Binding]`, `OneWayPropertyBinding`, `INotifyPropertyChanged`. ViewModel без логики в Start/Update; обновление из setter модели с проверкой изменения + `PropertyChanged`. Порядок инициализации: найти ViewModel **до** загрузки health из settings. Альтернатива FindObjectOfType — singleton/DI (упомянуто).
