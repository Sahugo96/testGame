## Суть урока

Для **изменяемых** данных (статистика, прогресс) — **сериализация** в универсальный текстовый формат. Курс: **JSON** (`JsonUtility` Unity) vs XML (.NET); разница для Unity минимальна. Практика: `[Serializable] PlayerStats`, счётчик выстрелов, `JsonUtility.ToJson` при смерти, сохранение в **`PlayerPrefs.SetString`**, загрузка в `Start` через `FromJson`. JSON как **строка** — готова к upload на сервер (4.4–4.5).
