## Суть урока

Практическая **Utility AI** на Hybrid ECS: `IBehaviour` (`Evaluate`, `Behave`), `BehaviorManager` (список behaviours + `ActiveBehaviour`), маркер `AIAgent` через `IConvertGameObjectToEntity`. Две системы: **`AI_EvaluateSystem`** (max score) и **`AI_BehaveSystem`** (execute active). Demo: `WaitBehaviour` (0.5f), `RotateBehaviour` (score ∝ 1/distance). Разделение evaluate/behave — для разной частоты тиков; люди «прикипают» к решению ~1–2 с.
