## Суть урока

Wwise Unity integration: Wwise Launcher → integrate может **зависнуть на Launching Unity** — workaround: создать **Wwise temp project**, скопировать **`StreamingAssets/Audio`** (GeneratedSoundBanks), **`.wproj`**, integration zips в целевой Unity project. Папка **`Assets/Wwise/`** + **`StreamingAssets`**. Удаление сломанной интеграции — через удаление Wwise project file из списка. Production использует Wwise project sound designer; программисты триггерят **Events** из кода (16.4). Integration хрупкая между версиями Unity — ожидать ручные шаги.
