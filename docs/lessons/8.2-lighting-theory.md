## Суть урока

Workflow «Как осветить проект» (slides): **выбор Render Pipeline** (Built-in / **URP** / HDRP / Custom SRP) → **режим Global Illumination** (Baked / Realtime / Mixed / None) → **Lighting Mode** (Baked Indirect, Subtractive, **Shadowmask**, Distance Shadowmask) → **Lights** (Baked/Realtime/Mixed) → **Emissive surfaces** → **Reflection probes** → **Light probes** (+ опционально **LPPV**). GI = direct + indirect (bounce). Baked — static, fast; Realtime GI — runtime, слабо на mobile.
