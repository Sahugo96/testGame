## Суть урока

Практика automated tests: создать test script из Test Runner; предпочитать **`[UnityTest]`** вместо default `[Test]` template для Play Mode. Использовать **`Assert`** (NUnit) для expectations. Пример: test pure logic (level-up thresholds, inventory rules) без full scene. **CI potential**: `-runTests` batchmode (упомянуто conceptually). Editor scripts могут automate repetitive QA (build smoke). Automated tests guard **regression** (18.2); не полная замена playtesting. Tests **fast and deterministic**.
