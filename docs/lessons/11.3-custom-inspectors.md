# Урок 11.3 — Кастомные инспекторы

## Мета

- **VTT:** `references/transcripts/11.3 Кастомные инспекторы.vtt`
- **Slides:** нет (~60% VTT — EditorWindow, ~40% CustomEditor)
- **Стандарты кода (слайды):** см. **CODE STANDARDS** → `editor-extensions.mdc`
- **Зависит от:** [11.2](11.2-editor-overview.md)
- **Статус:** `extracted`
- **Следующий:** [11.4](11.4-odin-inspector.md)

## Суть урока

Практика editor-скриптов в папке `Editor`: `EditorWindow` с `MenuItem`, `OnGUI`, поиск Settings через `AssetDatabase`, `GUIDToAssetPath`, batch-мутация + `SaveAssets`. Затем `CustomEditor`: `SerializedProperty`, `base.OnInspectorGUI()` vs ручной `OnInspectorGUI`, `ApplyModifiedProperties`, `CanEditMultipleObjects`. В конце — `OnSceneGUI` + `Handles`.
