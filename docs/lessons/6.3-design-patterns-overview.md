## Суть урока

Каталог **11 паттернов геймдева** (slide-01): **MVC/MVVM**, **ECS**, **Command**, **Observer**, **FSM**, **Factory**, **Object Pool**, **Singleton**, **EventBus**, **DI/IoC**, **Service Locator** (анти). По каждому — назначение и when-not (VTT + slides 02–12). ECS — парадигма курса; Command может реализовать FSM; Observer — async callbacks, **unregister**; FSM — Animator, плох при комбинированных состояниях; Pool — против GC spikes; Singleton — global state осторожно; EventBus — мало типов событий; **Service Locator — антипаттерн** vs DI.

## Не выносить в rules

- MVVM как отдельный мандат (упомянут родственником MVC).
- UniRx / reactive как обязательный стек.
- «Singleton = static здорового человека» без контекста.
