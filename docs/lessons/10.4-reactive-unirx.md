## Суть урока

**UniRx** (Asset Store, free): потоки **Observable**, **`Subscribe`**, операторы (**Throttle**, **Buffer**, **WhenAll**). Демо: детекция double-click через **`Observable.EveryUpdate()`** + фильтр ввода. **`ObservableWWW`** / параллельный **`Observable.WhenAll`** для сети (игра продолжает работать). Тяжёлая работа: **`Observable.Start`** + **`ObserveOnMainThread`** перед Unity API / Debug. **`Subscribe` на WhenAll** ждёт все tasks; отдельные потоки могут завершиться раньше. Не замена **Jobs** для mass sim.
