## Суть урока

**Animator** + **Avatar** + **SkinnedMeshRenderer**: анимируется **скелет**, mesh следует через skinning. **Animator Controller** — FSM (Idle, Attack, Walk…), **Transitions** по **Parameters** (bool `Walking` в демо). Импорт: mesh FBX (Rig) + **отдельные FBX клипов**; **Humanoid** retarget на другие модели. Unity импортирует **bone** и **blend shape** анимации, **не** transform-object keys из DCC.
