## Суть урока

Практика **PUN2 Free** (Asset Store): `PhotonServerSettings`, connect → **master** → room. **RPC** demo, затем **PhotonView** + `PhotonTransformView` / `PhotonAnimatorView` для sync. Игрок — **`PhotonNetwork.Instantiate`**; ввод только на **`IsMine`**. Hybrid ECS: `InputData` добавлять только для local player. Сетевой destroy — **`PhotonNetwork.Destroy`**. Отладка — clone-проект (symlinks). Demo упрощён; RPC «на всё» — не production.
