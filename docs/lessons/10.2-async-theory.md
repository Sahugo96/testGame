## Суть урока

**Async** — не блокировать main thread при I/O wait или heavy CPU. Подходы Unity: **Coroutines** (устарели, не multi-core), **Task/async-await** (.NET), **Jobs** (DOTS, blittable, max perf), **UniRx** (reactive streams, UI/input). Coroutines — yield без параллелизма; Task по умолчанию same thread, unless **Task.Run**; Jobs — struct + **NativeArray**.
