## Суть урока

Первый стандартный способ хранения **статических настроек** в Unity — **ScriptableObject**: asset-файл в проекте, не требует GameObject. Демо: класс `Settings` с `[CreateAssetMenu]`, asset `Game Settings`, ссылка из `CharacterHealth` — при `Start` здоровье берётся из SO. Теория: SO **вшивается в билд** и **не меняется** в рантайме у игрока; для live-баланса и прогресса — другие подходы (4.3+).
