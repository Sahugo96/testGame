## Суть урока

Workflow авторинга Wwise (для sound designer): **Import Audio Files** → создать **Event** → назначить sounds → добавить в **SoundBank** → **Generate SoundBanks**. Со стороны Unity: компонент **`AkBank`** загружает bank; **`AkEvent`** или **`AkSoundEngine.PostEvent`** проигрывает event. **`AkAudioListener`** заменяет/дополняет Unity listener. Тестировать в Wwise до Unity. Перегенерировать banks после изменений в Wwise. Большая часть UI Wwise — не ежедневная работа программиста; нужен pipeline hook при фиксации контента.
