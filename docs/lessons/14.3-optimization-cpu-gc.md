## Суть урока

**Update/FixedUpdate** — дорогой overhead на каждый MonoBehaviour (demo 10k cubes); один manager loop vs 10k Updates. Предпочитать **ECS** для горячих per-frame путей. **`Find*` / `GetComponent` / `Camera.main`** — never in Update; **кешировать в Awake/Start**. **GC**: избегать циклов alloc/destroy; **выделять при инициализации**, pool вместо Instantiate/Destroy (bullets). Паттерн **Object Pool**. **Camera.main** = FindWithTag. Quality settings — отключать неиспользуемые tiers.
