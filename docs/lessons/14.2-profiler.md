## Суть урока

Окно **Stats**: batches, setpass, tris, verts — базовая стоимость сцены. Тяжёлые категории: **SkinnedMeshRenderer** (CPU, bone weights 4→2), **Animator**, тени. **Window → Analysis**: Frame Debugger (GPU draws), Physics Debugger, **IMGUI Debugger**, **Entity Debugger** (ECS ms per system). Главный инструмент — **Profiler** (CPU/GPU/Memory/Rendering); Deep Profile — осторожно. Оптимизировать только после **измерений**, не наугад.
