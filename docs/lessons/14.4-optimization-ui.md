## Суть урока

Производительность UI: **не менять Text каждый кадр** — пересборка всего Canvas. Обновлять label только при изменении; **MVVM/event** из 12.5. **Pixel Perfect** дорог — выключать на HDPI. Предпочитать отключение **Image/Text component** вместо **GameObject.SetActive** (повторный Start). **Raycast Target** off на некликабельных элементах. **Color tint** одной texture вместо множества. **Canvas**: назначать **camera** явно (без Camera.main каждый кадр). **Many small canvases** лучше одного огромного always-dirty canvas. **SetActive** на pool objects — предпочитать renderer enable.
