## Суть урока

Практика **Unity Google Drive** package (git URL): Project Settings → OAuth (Google Cloud Console, External consent, credentials JSON → Parse). Утилита **`GoogleDriveTools`** (static): список файлов, **upload** string/bytes как `GameData.json`, **download** по file id; API **async/await**. Не core gameplay — но знать инструмент нужно. Напоминание: **бэкапы**, credentials не в репо.
