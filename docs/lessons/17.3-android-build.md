## Суть урока

Android build после SDK: **Keystore** (Create New in Keystore Manager) для signing. **External Tools**: JDK, Android SDK — часто **Android Studio SDK** предпочтительнее bundled; отключить Unity embedded SDK при mismatch. Ошибки: missing **SDK Platform / Build-Tools** → SDK Manager. **Gradle**: `mainTemplate.gradle`, `gradleTemplate.properties`, `baseProjectTemplate.gradle` — manual enable custom templates при conflicts. IL2CPP, min SDK bumped by SDKs. Ожидать **трение Gradle/SDK version** при каждом Unity upgrade — fix iteratively.
