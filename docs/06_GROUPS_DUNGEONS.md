## 7.8 Группы и раздача лута

**Группа:**
- В группе всегда есть лидер. Создатель группы становится лидером.
- Лидер может: приглашать и исключать, передавать лидерство, назначать помощников (в рейде), запускать проверку готовности и вход в подземелье. Режим лута лидер самостоятельно не меняет: он меняется только единогласным голосованием (см. ниже).
- Если лидер выходит из группы или теряет связь дольше таймаута (ДЕФОЛТ: 60 с), лидерство автоматически переходит к следующему по порядку вступления. Группа без лидера невозможна.
- Размер обычной группы задаётся в данных (ДЕФОЛТ: 5). Рейд: до 50 игроков, лидер рейда, помощники, подгруппы со своими лидерами (ДЕФОЛТ: подгруппы по 5).
- Режим лута один на всю группу (в рейде — на весь рейд). При создании группы действует стандартный режим «Поднявшему».

**Режимы лута (меняются единогласным голосованием):**

| Режим | Кто получает предмет |
|---|---|
| «Поднявшему» | Предмет лежит в луте, его получает тот подходящий игрок, кто поднял первым. Сервер арбитрирует: атомарный захват, победитель только один. |
| «Лидеру» | Весь лут достаётся лидеру группы. |
| «По очереди» | Предметы раздаются по кругу среди подходящих игроков. Указатель очереди хранится в группе и сдвигается на каждый предмет. |

**Голосование за смену режима лута:**
- Любой участник группы может предложить другой режим. Решение принимается только при согласии **всех** (100%) участников; у лидера нет особых прав в этом голосовании.
- Таймаут голосования: ДЕФОЛТ 30 с. Не проголосовавший считается «против». После провала новое предложение возможно через ДЕФОЛТ 60 с.
- Голосуют участники, находящиеся в сети; отключённые не блокируют голосование (ДЕФОЛТ).
- Любое изменение состава группы во время голосования отменяет его.
- Предложение, голоса (кто за и кто против) и результат отображаются в чате группы и пишутся в журнал.
- Серверная модель: `LootModeVote { proposalId, proposerId, newMode, votes[], expiresAt }`; сервер сам считает голоса; клиент отправляет `CmdVoteLootMode { proposalId, accept }`. Клиентскому подсчёту не доверяем.
- Рейд на 50 игроков: единогласие всех 50 нереалистично, поэтому в рейде голосуют рейд-лидер и лидеры подгрупп, решение также единогласное (ДЕФОЛТ); стандартный режим рейда «Поднявшему».

**Правила:**
- Подходящий получатель: член группы, участвовавший в бою с мобом (урон, лечение, баффы, контроль) и находящийся в радиусе от места смерти моба (ДЕФОЛТ: 50 м) в том же инстансе/зоне.
- «По очереди»: неподходящие игроки пропускаются без потери места в очереди; если у выбранного нет места в инвентаре, предмет достаётся следующему по очереди.
- «Поднявшему»: лут доступен ограниченное время (ДЕФОЛТ: 5 мин), затем пропадает.
- «Лидеру»: если у лидера нет места, предмет остаётся в луте на тот же срок, лидер видит уведомление.
- Смена режима действует на новый лут; уже выпавший лут раздаётся по режиму, действовавшему на момент выпадения. О смене режима уведомляются все.
- Журнал раздачи лута группы (кто и что получил) виден участникам и хранится для разбора споров.
- Соло: лут получает сам игрок. Лут боссов подземелья — персональный (раздел 7.5).
- Порог редкости (например, «режим действует до Редкого, выше — особые правила») — возможное расширение; ДЕФОЛТ: порога нет.
- Серверная модель: `LootEntry { definitionId, rolledData, eligibleMembers, mode, expiresAt }`; владелец назначается атомарно; настоящий экземпляр предмета (GUID) создаётся в момент выдачи.

## 7.5 Подземелье на 50 игроков

**Структура:**
- Инстанс на группу/рейд до 50 игроков; рейд состоит из подгрупп (ДЕФОЛТ: подгруппы по 5, до 10 подгрупп).
- Минимальный состав ролей (танки, лекари, урон) настраивается в данных подземелья.
- Инстанс живёт, пока в нём есть игроки или идёт таймер после прохода; прогресс сохраняется (локаут по боссам).
- Поддержка переподключения игрока в тот же инстанс.

**Энкаунтеры:**
- Система сценарных боёв: фазы, таймеры, призываемые мобы (adds), раздражение/берсерк-таймер.
- Таблица угрозы (threat) для боссов и мобов.
- Механики для большой группы: области урона, метки на игроков, разделение на подгруппы по задачам.

**Лут:** с обычных мобов действует режим лута рейда (раздел 7.8); лут боссов персональный (каждый участник получает свой с сервера, без споров) — ДЕФОЛТ.

**Технический бюджет (стартовые гипотезы, измерять и корректировать):**
- Серверная симуляция 20–30 Гц; сетевые снимки дальних объектов реже (10–15 Гц).
- Ограничить число одновременных эффектов и полос здоровья/ников на экране, сжимать данные, использовать interest management по сетке.
- Целевые метрики: время тика сервера, трафик на игрока, число сущностей в инстансе — мерим ботами (см. модуль 3).

**UI для рейда:** компактные рамки группы/рейда, цель цели, фильтры боевого лога, прореживание VFX.
