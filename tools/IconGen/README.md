# IconGen — значки игры

Рисует значки предметов, навыков, статусов и кнопок окон. Графика своя (SVG из кода), сторонних ассетов нет.

Результат: `My project/Assets/_Project/Resources/Icons/<группа>/<Icon>.png`, 128×128, без прозрачности.
Группы: `items`, `skills`, `statuses`, `windows`. Имя файла — значение поля `Icon` в контенте.

## Запуск

Нужны Python 3 и Node.js с пакетом `playwright` (Chromium). Из корня репозитория:

```bash
python3 tools/IconGen/icons.py
```
```bash
node tools/IconGen/render.js
```

Первая команда пишет SVG в `tools/IconGen/svg/` (в git не хранится) и создаёт `.meta` для новых значков (существующие `.meta` не трогает — GUID не меняется). Вторая рендерит PNG.

Лист со всеми значками для просмотра:

```bash
node tools/IconGen/render.js --sheet sheet.png
```

## Как добавить значок

1. В `icons.py` написать функцию, которая возвращает SVG-фигуры в поле 128×128 (примеры — `sword`, `potion`, `fireball`). Градиенты — через `g(lin(...))` / `g(rad(...))`, контур — `OUTLINE`.
2. Добавить строку в таблицу `ICONS` в нужную группу: ключ — значение `Icon` из контента, значение — `frame(фон, функция, цвет_свечения)`.
3. Выполнить обе команды, посмотреть результат, закоммитить PNG и `.meta`.

Проверка полноты: тест `IconFilesTests` (`cd sim-tests && dotnet test`) падает, если у предмета, навыка, статуса или окна нет картинки.
