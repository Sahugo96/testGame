# LoadTest — нагрузочный тест (модуль 3)

Тот же серверный код и те же боты, что компилирует Unity, но без Unity. Нужен .NET 8 SDK.

```bash
cd tools/LoadTest
dotnet run -c Release -- local 50 60
```
Сервер и 50 ботов в одном процессе (через настоящие TCP-сокеты на 127.0.0.1), 60 секунд. Каждые 5 с печатаются метрики, в конце строка `RESULT`: время тика (среднее, 99-й перцентиль, максимум и бюджет тика), сколько сущностей видит игрок из скольких есть, исходящий трафик на игрока.

```bash
dotnet run -c Release -- connect 192.168.1.10 7777 20
```
20 ботов подключаются к уже запущенному серверу (хост в игре или `StartServer.bat`). Остановить — Ctrl+C.

```bash
dotnet run -c Release -- sizes
```
Размер одного снимка мира и состояния игрока в байтах.

Без .NET ботов можно запустить из собранной игры: `StartBots.bat` рядом с `MyGame.exe` (или `MyGame.exe -batchmode -nographics -bots 20 -connect АДРЕС -port 7777`).
